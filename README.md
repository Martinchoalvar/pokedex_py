Pokédex en Terminal

Este es un proyecto sencillo en Python para consultar información de Pokémon directamente desde la consola

La idea principal fue practicar manejo de diccionarios y flujos iterativos en la terminal.

---

## 🎮 ¿Qué se puede hacer?

- Buscar cualquier Pokémon por nombre o ID.
- Filtrar Pokémon por su tipo (fuego, agua, planta, etc.).
- Ver stats y datos principales organizados en pantalla.
- registrar pokemon nuevo.
